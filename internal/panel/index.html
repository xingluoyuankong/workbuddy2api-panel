账号代理出口

—
每个账号可绑一条独立代理：socks5://user:pass@host:port 或 http://user:pass@host:port。 「校验」会实测三件事——① 走这条代理的真实出口 IP（多源交叉，防单源被缓存）； ② 与本机直连出口比对，出口 = 直连即判定代理没生效； ③ 与声明 IP 比对，不符或多源不一致（出口轮换）即按 account_proxy.on_mismatch 处置。
订阅链接池 点击展开管理
global 与 cn 各自独立的出口池（两池不互通）。每 6 小时自动拉取，解析出的代理链接进入对应 realm 的出口池；出口失败自动降权重试，TLS 劫持（证书校验失败）长熔断并在命中 3 次后永久剔除。可直接粘贴代理链接（带凭据的 http/socks5，立即入池），也可粘贴订阅 URL 自动拉取；vmess/vless 暂不支持。
三种写入方式：添加 = 只把文本框里的新链接接到池尾，已有条目原样保留；替换 = 用文本框内容整体覆盖（文本框里没有的条目会被删掉）；清除 = 清空该池，该 realm 回落直连。

配置代理 

      
声明出口 IP 一般留空：聚合代理的出口会实时轮换，系统每次校验都实测最新出口、验证调用确实走这条代理。仅当你确定出口固定不变（固定 IP 住宅代理）才填写，填写后出口不符将按失配策略处置。代理链接里的 host 是入口，与出口无关，别把入口 IP 填进来。
